Chris turns a repeated data-science review ritual into Pi skills: make the first artifact a plan, audit that plan, hand it back to an implementation agent, then review the resulting code with the same discipline.

WHAT HE SHOWED

Chris showed an agentic plan-review loop for data-science code, with the human inserted at the decision points. The concrete task was a PyMC distribution change: ask an agent for a plan, review the plan, hand the reviewed plan to an implementation agent, then review the implementation.

The loop keeps planning, review findings, implementation, and implementation review as separate artifacts, so the human can inspect and steer the work instead of trusting a single agent pass.

WORKFLOW MOVES

the portable parts of Chris's plan-review and implementation-review loop
Make the first artifact a planFor the PyMC half-flat distribution demo, the first agent job is to produce an implementation plan, not start editing code.
Turn repeated review into a skillChris made `review plans` because he kept asking for the same audit in the same way.
Write review findings to markdownThe review skill writes a local report with red and yellow flags instead of leaving feedback trapped in chat.
Send the reviewed plan backThe review report becomes input to the implementation stage, either for the original agent or another instance.
Route models by tasteChris chooses review and implementation models from experience rather than hard-coding one model for every role.
Review the implementation tooAfter code is written, `review implementation` audits the finished work against the plan and project expectations.
Keep the skills in a living repoChris saves the skills in `cutie-pi` so the review ritual can stay current with his projects.

SKILLS & WORKFLOWS

the reusable pieces from Chris's setup
skill

review plans

Reads an implementation plan, finds red and yellow flags, and writes review findings to a local markdown file.

skill

review implementation

Audits the implemented code after the plan has passed review and the coding agent has made changes.

skill

Socratic Review

Asks questions before implementation so the agent clarifies uncertainty instead of building too early.

workflow

model routing by task

Chris switches instances and models by experience: review, data science, and coding can each use different strengths.

WHAT HE SHOWED

Doug showed an auto-research loop for search-ranking code. The worked example is a BM25-style scoring function on MS MARCO: the agent inspects training queries, tries temporary patches, and asks to keep a change only after it has seen training feedback.

The apply step is judged on validation data the agent cannot inspect. That split is the point of the workflow: let the agent experiment aggressively, then let hidden validation decide which search changes survive.

PRINCIPLES

the portable ideas inside Doug's auto-research loop
Work on one search problemChoose one scoring function and one dataset where improvement can be measured. Doug's demo uses BM25-style ranking on MS MARCO.
Give the agent concrete actionsThe agent can inspect queries, try a patch, apply a patch, revert changes, and run evals. The edit surface stays narrow.
Hide the test it must passTraining queries are visible for diagnosis. Validation queries decide whether a proposed change generalizes.
Let patches run in a sandbox`tryout patch` creates a temporary scoring function and returns detailed training feedback before anything is saved.
Gate changes with validationThe apply step keeps a patch only when holdout performance improves, regardless of how plausible the agent's explanation sounds.
Expect known ideas fasterThe useful changes were familiar search moves such as stop-word handling and phrase boosts, tested quickly against a local metric.
Serialize the research roundsOne run produces a changed scorer and a summary. The next run starts from that output instead of one long autonomous session.
Return judged feedback as user inputFor agentic search, Doug sends result judgments back as a user-visible message because that changes agent behavior more reliably.

SKILLS & WORKFLOWS

the reusable pieces from Doug's setup
workflow

auto-research agentic search

A loop for making search-ranking changes with an agent while keeping validation data outside the agent's view.

tool

tryout patch

Creates a temporary search-scoring function, runs training-query feedback, and lets the agent revise before applying a change.

gate

hidden validation

Accepts or rejects a proposed patch using holdout performance, which prevents most query-specific ranking hacks.

workflow

judged search feedback

Labels search results with a simple judge and sends that judgment back to the agent as a user message.

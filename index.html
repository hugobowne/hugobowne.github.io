Building AI Agents: the open-source course

self-paced · free · 6 sections
A self-paced course on building agent harnesses. Posts, podcasts, workshops, and code from me and my collaborators — plus links to a few external resources too. A more detailed guide here ↗

An agent is just an LLM calling tools in a loop. A harness is everything around it: tools, context, hooks, sandboxes, memory, the loop itself. The LLM is the brain. The harness is the body.

// workshop progression

Build one agent from the model call up.

Throughout the workshop, you build a customer service agent that answers product questions, looks up orders, uses tools, remembers context, and prepares consequential actions for human approval. The example gives us something concrete to build and debug. The architecture applies to agents across many different domains.

stage 02

Build the tool-calling loop.

You give the model tool definitions and write the control loop. The model requests a tool, your code runs it, and the result goes back to the model. You can inspect every step and see why token use grows as the conversation history is sent again.

stage 04

Rebuild the agent with the OpenAI Agents SDK.

You replace the hand-written loop with Runner, add session memory, and use SDK tools, guardrails, and tracing. Because you built the loop and harness first, you can see what the SDK handles and what still belongs to your application.

uv run python workshop/04_agents_sdk/agents_sdk.py Tools the Runner called for us: lookup_order I checked order ORD-1001. It shipped, but the carrier scan hasn’t changed for 4 days in the Melbourne depot... # the schemas, dispatch table, and while loop are gone. find where they went.

stage 05

Turn it into reusable architecture with MCP.

You move the tool surface behind an MCP server and connect it to browser chat, terminal chat, and scheduled work. The complete system can file tickets, create pending refund requests, and draft overdue-delivery outreach while keeping approval and sending in human hands.
